## 1. (a) A regra de lint que morde

`apps/web/eslint.config.mjs`, um bloco novo antes do `globalIgnores`:

```js
  {
    files: ['**/*.{ts,tsx}'],
    rules: {
      'no-restricted-imports': [
        'error',
        {
          paths: [
            {
              name: 'cn',
              message:
                "Importa `cn` de '@/lib/utils' — é o que tem a escala de texto do tema. O motor `'cn'` só se toca em `lib/utils.ts`, por `'cn/config'`.",
            },
          ],
        },
      ],
    },
  },
```

**`'cn/config'` fica permitido**: `no-restricted-imports` com `paths` bloqueia o especificador **exato**
`'cn'`; `'cn/config'` é outro nome e não é restringido — é o que `lib/utils.ts` usa para construir o
`createCn`, e o lint da app continua verde com ele lá.

**Prova, com um ficheiro temporário `apps/web/src/t95-temp-cn.ts`:**

```

exit 1
```


## 2. (b) O shim do `shared` deixou de mentir — **apagado**

`packages/shared/src/utils/cn.ts` reexportava o `cn` nu e o docblock afirmava «so the entire workspace has
exactly one Tailwind class-conflict engine» — falso desde a T90, em que a app passou a ter o `cn`
estendido em `lib/utils.ts`.

**Escolhi apagar** (e não reduzir a uma nota). O custo de cada opção:

| opção | custo |
| --- | --- |
| **apagar** (escolhida) | uma linha fora de `utils/index.ts`; o pacote `cn` continua na raiz e o `./utils` do `shared` continua a apontar para um ficheiro que existe; sem mudança no `package.json` |
| reduzir a nota | um ficheiro vazio a fingir de documentação, exportado por `utils/index.ts`, que o próximo leitor volta a interpretar como API |

**Ninguém o importava:** `grep -rn "@repo/shared/utils" apps packages` só dá o **comentário** de
`packages/shared/src/index.ts:8` (a lista de entry points). `ClassValue` também só aparecia nesse
ficheiro (`grep -rn ClassValue` → 1 ocorrência, o próprio export).

```diff
--- packages/shared/src/utils/index.ts
-export * from './cn';
 export * from './currency';
```

e `packages/shared/src/utils/cn.ts` apagado. O `package.json` do `shared` não mudou: `./utils` aponta
para `src/utils/index.ts`, que continua a existir.
