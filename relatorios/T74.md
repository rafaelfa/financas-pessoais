### 11.3 Uma coisa que vi e **não** corrigi (decisão declarada, para a T77)

No passo `G4` — campo com `12,34` depois de um submit inválido — o erro anterior continua no campo:

```
G4 texto "12,34" | botao=activado | erro="O valor não pode ser zero." | ... "inputAriaInvalid":"true"
```

É uma mensagem falsa com um valor válido no campo, do mesmo tipo do achado B. Cheguei a implementar a limpeza no `onValueChange` e reverti-a antes do gate: o meu próprio relatório (§9) põe «limpar erro ao digitar» na T77, e o perfil diz que o que está fora do âmbito se anota, não se corrige. O que serve de remédio, para quem pegar na T77:

```ts
onValueChange={(value) => {
  setAmountInCents(value);
  if (value === null) return;
  setFieldErrors((previous) => {
    if (previous.amountInCents === undefined) return previous;
    const next = { ...previous };
    delete next.amountInCents;
    return next;
  });
}}
```
